# ClipX 使用文档

## 1. 产品定位

ClipX 是一个本地剪贴板历史工具，用于增强 Windows 的复制粘贴工作流。它可以记录文本和图片，支持搜索、置顶、复制回剪贴板、快速粘贴，以及可选接管 `Win+V`。

## 2. 启动方式

### 托盘启动

应用启动后默认常驻托盘：

- 左键托盘图标：显示或隐藏主面板
- 右键托盘图标：打开托盘菜单

### 快捷键启动

默认快捷键：

```text
Alt+V
```

如果启用了“替代 Windows 剪贴板历史”：

```text
Win+V
```

## 3. 主界面说明

主界面包含以下区域：

- 顶部搜索栏
- 剪贴板历史列表
- 设置入口
- 清空入口

主窗口在失焦时会自动隐藏。

## 4. 剪贴板记录功能

### 文本记录

复制文本后，ClipX 会自动写入历史列表。

### 图片记录

复制图片后，ClipX 会：

- 将图片保存到数据目录下的 `images/`
- 在历史列表中显示为图片项
- 支持点击打开单独预览窗口

### 去重逻辑

对于连续复制的相同内容，应用会基于哈希做最近一次内容去重，避免重复刷屏。

## 5. 历史列表操作

每条记录支持以下操作：

- 点击整条记录：将该记录写回系统剪贴板并自动执行粘贴
- `复制`：仅写回系统剪贴板，不自动粘贴
- `置顶`：固定重要内容
- `删除`：删除单条记录

## 6. 搜索

搜索框支持按内容关键字检索。

当前实现支持：

- 文本内容匹配
- 类型关键词匹配：`image`、`图片`、`text`、`文本`

## 7. 设置说明

设置面板当前主要分为以下区块。

### History

`最大保留条数`

- 用于限制非置顶记录数量
- 范围：`1 - 500`
- 超出后自动清理较旧的非置顶记录

### Hotkey

`唤起面板快捷键`

- 可使用预设快捷键
- 可手动输入快捷键
- 支持字母、数字、`F1-F12`、`Space`、`Backquote`

如果启用系统替代模式：

- 快捷键固定为 `Win+V`
- 手动输入会被禁用

### System

`替代 Windows 剪贴板历史`

含义：

- 关闭系统原生 `Win+V` 剪贴板历史
- 改由 ClipX 接管 `Win+V`

行为说明：

- 勾选后需要点击“保存”才真正生效
- 保存成功后会修改系统注册表并启用低层按键接管逻辑

### Startup

`开机自动启动`

行为说明：

- 该项为即时生效
- 点击后立即调用系统自启动接口

### Storage

`数据存储位置`

支持：

- 打开当前数据目录
- 迁移到新目录

迁移后应用会自动重启。

## 8. 托盘菜单

当前托盘右键菜单包括：

- `显示面板`
- `设置`
- `隐藏托盘图标`
- `退出`

### 隐藏托盘图标

点击后会临时隐藏托盘图标。下次通过程序再次显示主窗口时，托盘图标会自动恢复显示。

## 9. 快捷键替代说明

启用“替代 Windows 剪贴板历史”后，实际发生的事包括：

1. 关闭 Windows 原生剪贴板历史注册表开关
2. 应用在后台拦截 `Win+V`
3. 打开 ClipX 主窗口，而不是系统面板

关闭该功能后：

1. 恢复系统剪贴板历史开关
2. 应用停止接管 `Win+V`
3. 若当前快捷键仍是 `Win+V`，会回退到默认 `Alt+V`

## 10. 数据文件说明

数据目录中主要包含：

```text
clipx.db
images/
```

其中：

- `clipx.db` 存储剪贴板记录和设置
- `images/` 存储图片剪贴板内容文件

## 11. 常见问题

### 1. 为什么勾选后还要点保存？

因为“替代 Windows 剪贴板历史”不是纯前端选项，它会修改系统级行为，所以当前产品设计是保存后生效。

### 2. 为什么开机启动勾选后立即生效？

因为它属于即时系统设置，当前设计就是点击后直接调用后端接口。

### 3. 为什么窗口会自动消失？

主窗口失焦后会自动隐藏，这是当前交互设计，用于实现轻量浮窗式体验。

### 4. 为什么置顶项不会被清理？

容量清理只作用于非置顶项，避免重要内容被自动删除。

## 12. 多端同步与手机端使用

ClipFlow 支持 Windows 电脑与手机端在局域网内通过 **端到端加密（E2EE AES-GCM）** 实时互通剪贴板：

1. **电脑端出码**：
   - 打开电脑端「偏好设置 → 多端同步」；
   - 点击「扫码配对」，界面将生成包含动态加密密钥的一次性配对二维码。
2. **手机端扫码**：
   - 在手机上打开 ClipFlow Mobile App（若未配对，会自动启动扫码镜头）；
   - 对准电脑屏幕上的二维码，即可毫秒级完成安全配对。
3. **双向无缝传输**：
   - **电脑 → 手机**：电脑端复制的内容将通过加密通道实时推送到手机列表，轻触手机卡片即可复制；
   - **手机 → 电脑**：点击手机底部的「发送手机剪贴板至电脑」，手机内容即刻同步至 Windows 剪贴板。

## 13. 故障排查

如果遇到设置不生效，可按以下顺序排查：

1. 完整关闭并重新启动应用
2. 在设置中再次确认保存后的显示状态
3. 检查是否存在安全软件阻止全局快捷键或键盘钩子
4. 检查系统是否禁用了 WebView2 或相关桌面组件
5. 查看终端中的 `pnpm tauri dev` 输出日志
